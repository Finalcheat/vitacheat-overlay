# VitaCheat Overlay 0.8.50

A full-screen PS Vita cheat-list overlay by FinalCheat.

## Highlights

- Game title, installed version, Title ID, pagination, and clear selected/enabled states.
- Direct UTF-8 and GBK VitaCheat `.psv` loading.
- Five menu languages and a system-language option.
- Adjustable opacity, opening shortcut, and Asian/Western confirm and back controls.
- Independent execution engine with saved-byte restoration for A-family patches.

## Installation

Download `VitaCheatOverlay-0.8.50.zip`, copy the five files in `ux0/vitacheat/` to `ux0:vitacheat/`, and add Kernel to `*KERNEL` and Shell to `*main`. Fully restart. Default opening shortcut: **L + SELECT**; toggle entries with **Square**.

Keep existing `.psv` files in `ux0:vitacheat/db/`. The original VitaCheat may remain installed; enable the same entry separately when comparing plugins.

Settings schema is v6. Downgrades require the matching older settings backup or resetting the VCO settings file.
